# Presentation Size is saved in the Presentation, not per machine

The Presentation Size is written to `presentation.json`, while the Performance Layout and the displays stay in the per-machine settings, so a vertical Presentation and a landscape talk each open at their own shape on any machine; the trade-off is one shape per Presentation App instead of one remembered size per machine, and it is surprising because every other Perform setting is per machine. It is hard to reverse because it is part of the folder format (ADR 0006). There is no format version bump: a file without `presentationSize` reads as 1920×1080, an older app ignores the field and falls back to 1920×1080 when it saves, and a size left in the machine settings by an older version is ignored rather than migrated.
