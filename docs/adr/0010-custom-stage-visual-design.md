# Custom Stage visual design over a native macOS look

The app uses its own visual language, Stage, rather than native macOS styling: rounded type, pill buttons, borderless floating cards on a tinted background, a violet accent with a gradient for primary actions, and a solid red Record button. Prototype time-to-present-59 mocked four directions (Studio, Paper, Stage and Native macOS) on the Editor, Start Window and Performance Bar, and the human chose Stage. The trade-off is that the app no longer looks like a stock Mac app and every control is styled by hand. Design tokens, the CSS custom properties in `apps/desktop/src/styles/tokens.css`, are the single source of the look: components use tokens, never literal values. The app follows the system light or dark appearance but not the system accent colour, so the violet is the same on every Mac, and there is no in-app theme switch.
